
🚗 Smart Parking IoT System

An IoT-based smart parking system combining vehicle safety alerts, real-time parking slot monitoring, and an online booking dashboard.

✨ Features

- 🚘 Ultrasonic-based vehicle distance detection
- 🚦 Green, yellow, and red LED safety indicators
- 🔊 Buzzer alert for nearby obstacles
- 🅿️ Real-time monitoring of parking slot availability
- 📶 ESP32-based Wi-Fi connectivity
- 🌐 Web dashboard for parking status
- 📅 Parking slot booking interface
- 🚧 Servo-controlled gate status display

🧰 Hardware Components

- Arduino Uno

🔌 Working Principle

The Arduino-based safety subsystem measures the distance between a vehicle and an obstacle and provides visual and audible warnings.

The ESP32-based monitoring subsystem detects parking slot occupancy and displays the status on a Wi-Fi dashboard. The interface is designed to show available slots, occupied slots, gate status, activity logs, and booking details.

Note: Online booking, activity logging, and automatic gate control depend on their actual implementation and integration with the hardware.
